# MediCare EHR System

نظام السجلات الطبية الإلكترونية مبني باستخدام Flask وجلسات المستخدمين.

## 📋 المميزات

- ✅ نظام مصادقة باستخدام الجلسات (Sessions)
- ✅ إدارة المرضى وسجلاتهم الطبية
- ✅ إدارة الحالات المرضية والزيارات
- ✅ نظام المواعيد والتقويم
- ✅ لوحة تحكم إحصائية
- ✅ واجهة مستخدم عربية متجاوبة
